# Portfolio Website

This repository contains a personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Responsive portfolio layout
- About, projects, skills, learning, experience, certificates, and contact sections
- Interactive project cards and edit-friendly portfolio content
- Simple Node.js/Express server for local preview

## Run locally

```bash
node server.js
```

Then open http://localhost:3000 in your browser.

## Technologies
- HTML
- CSS
- JavaScript
- Node.js
- Express
